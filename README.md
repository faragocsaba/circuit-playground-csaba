# Circuit Playground Csaba

I want to create a web application which illustrates how electronic elements work. Let's start with transistors! Create an animation where all the possibilities (pnp vs. npn and common base vs. common collector vs. common emitter) are demonstrated. The user may change the layout and the current, and it shows how the transistor works.
